# Medical Insurance Cost Prediction

> Midterm project — ML Zoomcamp 2026

Predicting the annual medical insurance cost (`charges`) of an individual from
demographic and lifestyle features, using supervised regression.

---

## Problem statement

Health insurers price policies based on the expected medical cost of each
insured person. Estimating that cost accurately from simple, self-reported
attributes (age, BMI, smoking status, region, ...) helps insurers:

- set fair and risk-adjusted premiums,
- flag high-risk profiles for prevention programs,
- give customers a transparent cost estimate.

**Task:** given a person's profile, predict their annual medical `charges`
(a continuous amount, in USD). This is a **regression** problem.

**Metric:** RMSE (root mean squared error) on a held-out test set, reported in
USD. MAE is also reported because it is easier to interpret for a business
audience.

---

## Dataset

- Source: [insurance.csv](https://raw.githubusercontent.com/stedy/Machine-Learning-with-R-datasets/master/insurance.csv)
- Size: 1338 rows, 7 columns
- Target: `charges`
- Features:

| Column     | Type        | Description                          |
|------------|-------------|--------------------------------------|
| `age`      | numeric     | age of the insured person            |
| `sex`      | categorical | female / male                        |
| `bmi`      | numeric     | body mass index                      |
| `children` | numeric     | number of children covered           |
| `smoker`   | categorical | yes / no                             |
| `region`   | categorical | residential area (4 regions)         |
| `charges`  | numeric     | **target** — annual medical cost     |

The dataset is committed in this repository as `insurance.csv`.

## EDA summary

- No missing values.
- Target `charges` is right-skewed: mean ≈ $13,270, median ≈ $9,382.
- `smoker` is by far the strongest signal: average charge ≈ $32,050 for smokers
  vs ≈ $8,434 for non-smokers.
- `age` and `bmi` correlate positively with `charges` (r ≈ 0.30 and 0.20).
- Region and sex have a weak effect compared with smoking status.

---

## Modeling

Several models are trained and compared with 5-fold cross-validation:

| Model                     | RMSE (CV) | MAE (CV) |
|---------------------------|-----------|----------|
| Dummy baseline (mean)     | 12074.54  | 9123.03  |
| Linear Regression         | 6117.02   | 4215.50  |
| Ridge Regression          | 6116.99   | 4221.19  |
| Random Forest             | 4900.12   | 2764.68  |
| XGBoost                   | 4883.33   | 2789.22  |

XGBoost achieved the lowest cross-validated RMSE, so it was selected as the
final model.

**Selected model:** `XGBoost` — saved to `model.pkl`.
On the held-out test set: RMSE ≈ 4585.54, MAE ≈ 2604.57.

## How to run

### 1. Environment

```bash
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
# to run the notebook as well:
uv pip install jupyter
```

### 2. Train the final model

```bash
python train.py
```

This reads `insurance.csv`, trains the selected model and writes `model.pkl`.

### 3. Start the web service

```bash
uvicorn serve:app --host 0.0.0.0 --port 9696
```

Health check:

```bash
curl http://localhost:9696/health
# {"status": "ok"}
```

Prediction:

```bash
curl -X POST http://localhost:9696/predict \
  -H "Content-Type: application/json" \
  -d '{"age": 35, "sex": "male", "bmi": 27.5, "children": 1, "smoker": "yes", "region": "southeast"}'
```

Expected response shape:

```json
{"charges": 19657.62}
```

## Docker

Build the image:

```bash
docker build -t insurance-cost .
```

Run the container:

```bash
docker run -it --rm -p 9696:9696 insurance-cost
```

Then use the same `curl` commands as above against `http://localhost:9696`.

## Limitations and next steps

- The dataset is small (1338 rows); results have high variance.
- The model is a point estimate: no prediction intervals yet.
- Possible improvements: target transformation, interaction features
  (smoker × bmi), gradient boosting tuning, and monitoring for data drift.
